## Reject filter (skip these)

- Requires **US work authorization** / US-onsite-only with no remote option
- Requires **employer visa sponsorship** outside the UK
- **Senior / Staff / Principal / Lead / EM / Director / VP** as a hard requirement
- **CS/EE degree required** as hard filter, or **5+ years professional SWE** as hard minimum
- Pure **SRE / DevOps / infra-only / data-eng** with no product or customer surface
- **ML research** requiring PhD / first-author publications
- Big-tech grad-scheme LeetCode gauntlets (deprioritize unless user wants one)

## Search instructions for an AI agent

1. For each company Tier 1 → 6, scrape the careers URL and list **all open roles** matching the titles in "Role titles to search for."
2. For each match, return:
   - Company, role title, location (incl. remote/hybrid + UK vs international), seniority, URL
   - **Match score (1–5)** using the "flag a JD as match" checklist + the reject filter
   - **Top 3 CV bullets** that map to the JD's must-haves
   - **One concern** (e.g., asks for 5 yrs, US-only, requires Go/Rust he doesn't have)
3. Sort by: tier asc → match score desc → location (London > UK-remote > EU-remote > US/global-remote).
4. Cap output at 20 strongest matches per run. Don't pad.
5. For Tier 5 (YC), search `workatastartup.com` filtered by recent batches AND "Founding Engineer" / "Forward Deployed" / "Applied AI".
6. **Hard-skip** anything in the reject filter (Senior+, US-onsite-only, CS-degree-required, 5+ yr minimum, pure infra/research).

## What to do with results

- Apply to **2–3 per day** with a tailored note. Quality over volume.
- **Lead every application with the GitHub link** (`github.com/Jimmy6929`) — reading real code clears the "can he build?" screen fastest.
- For each Tier 1–2 hit, also send a **LinkedIn DM** to the hiring manager or a founder (adapt the YC Outreach templates).
- For US-remote (Tier 4) roles, confirm they hire international-remote / contractor / EOR **before** investing in a tailored application.
- Log every application in the Job Tracker (`data/applications.md`).
